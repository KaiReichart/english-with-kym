# Variant 04 — "Haltung" (Neo-Brutalism)

A loud, high-contrast take on the homepage: thick black borders, hard offset
drop-shadows, and flat saturated colour blocks (yellow / cobalt / pink) on a
warm cream backdrop with a subtle halftone-dot texture. Headlines are stacked
like sticker type in Archivo Black; body copy sits in chunky bordered cards so
the long-form German copy stays easy to scan despite the raw aesthetic.
Buttons and nav links shift on hover/press like a physical sticker lifting
off the page — energetic and a little irreverent, aimed at teens without
losing legibility or AA contrast.

## Fonts

- **Archivo Black** — headlines, eyebrows, offer titles, stickers.
- **Space Grotesk Variable** — body copy and UI text.
- **JetBrains Mono Variable** — small caps labels, chips, section numbers.

## Colour palette

- `--ink: #111111` — borders, primary text, dark bands.
- `--paper: #fff8e9` — page background (warm cream, halftone dot texture).
- `--white: #ffffff` — cards, header.
- `--yellow: #ffd400` — hero band, primary accent.
- `--cobalt: #2a3ffb` — contact band, secondary accent (white text, ~6.5:1 contrast).
- `--pink: #ff4fa0` — about band, tertiary accent (black text, ~6.9:1 contrast).

All accent/text pairings were checked for WCAG AA contrast (≥4.5:1 for body
text, ≥3:1 for large bold headlines).
