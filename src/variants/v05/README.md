# Variant 05 — The Schwabmünchen Line

British heritage / classic London. The page borrows its visual grammar from
Penguin book-cover design and London Underground / enamel station signage:
a recurring navy–red–cream tri-band rule, book-cover-style offer cards with
coloured spines, and original roundel-style numbered markers (a plain ring +
bar, not the TfL logo) that count off each section like stops on a line.
Photography (Big Ben, a red phone box) is framed in cream "postcard" mounts
with a thin red keyline.

## Fonts

- **Libre Baskerville** — headings, body copy, pull-quotes (the literary,
  Penguin-paperback voice)
- **Inter** (variable) — nav, labels, eyebrows, buttons (the clean,
  signage-style sans)
