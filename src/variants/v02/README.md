# Variant 02 — Swiss / International Typographic Style

A strict modular grid, flush-left type set in Space Grotesk, and a single
red accent on black/white. Sections are numbered like a Müller-Brockmann
poster (01 Lernen → 05 Kontakt), thin hairlines mark a 6/12-column grid
behind every section, and the three tutoring photos are desaturated to
black and white so they read as part of the grid rather than decoration.
Black and white sections alternate to give the long page rhythm, with red
reserved for numerals, underlines, and button fills — never as small body
text, to keep contrast comfortably AA.

**Fonts:** Space Grotesk Variable (display/headings, numerals), Inter
Variable (body text).

**Palette:** `#ffffff` paper, `#0d0d0d` night, `#b3001b` red accent,
`#111111` ink / `#f5f5f5` night text, with muted greys for secondary copy.
