# Variant 09 — Groovy Schwabmünchen

A warm, sun-drenched 70s poster look for English with Kym: chunky Shrikhand
display type, sunburst motifs spinning gently behind the hero and contact
sections, rounded arc dividers between sections, and a subtle film-grain
overlay for a vintage print feel. Photos are given a sepia/contrast treatment
and framed in bold hand-drawn-style borders with hard drop shadows, echoing
retro travel-poster illustration.

## Fonts

- **Shrikhand** — display headlines (brand, section headings)
- **Bebas Neue** — labels, nav, section tags, taglines, buttons
- **Nunito Variable** — body copy

## Palette

- Cream `#f6e8c9` / cream-light `#fcf4e2` — page background, cards
- Mustard `#e3a23c` — accents, about section background
- Orange `#d9622b` — primary CTA, icon fills
- Rust `#a8401e` — headings, contact section background
- Brown `#4a2a18` / brown-dark `#2e1a0f` — text, borders, learn section background
